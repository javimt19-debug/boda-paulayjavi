# Boda Paula & Javi · 03.10.2026

Web de invitación para nuestra boda en Alicante.

## Estructura

- `index.html` — Página principal
- `images/` — Fotos del sitio (nosotros, Monasterio de la Santa Faz, Finca Torre Juana)
- `netlify.toml` — Configuración de despliegue para Netlify

## Despliegue

El sitio está desplegado en Netlify, conectado a este repositorio.
Cualquier cambio en la rama principal se publica automáticamente.

## Formulario de confirmación

El formulario de RSVP envía los datos directamente a un Google Form,
que vuelca las respuestas en un Google Sheet asociado.
